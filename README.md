# Hi, I'm Ryan 👋

I'm a Computer Science student at the National University of Singapore, focused on vulnerability research and application security.

My experience includes researching vulnerabilities in a modern JavaScript engine, testing Android applications with Frida, and evaluating AI-assisted approaches to vulnerability research. I also build full-stack applications and security automation.

## 🔬 Security interests

- JavaScript engine and browser security
- Vulnerability discovery and exploitation
- Mobile security and dynamic instrumentation
- Fuzzing and program analysis
- AI-assisted vulnerability research

## 💻 Projects

### CVE Lab

A private research project where I review open-source software, validate potential vulnerabilities in isolated environments, and report confirmed findings through coordinated disclosure.

### Super Savers

A full-stack platform built with React and Node.js that collects live prices in parallel using Playwright.

- Streamed results to the frontend using Server-Sent Events
- Used Supabase and PostgreSQL with Row-Level Security
- Integrated Gemini for search suggestions
- Added fallbacks and caching to reduce unnecessary API calls

### Cloud Access Control and Audit Logging

A Google Cloud project focused on controlling access to protected resources and maintaining an auditable record of activity.

- Implemented access controls for protected resources
- Configured cloud logging for security monitoring and auditing
